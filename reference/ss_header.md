# Designation of header rows for custom sstable

This function set the designated rows as header rows of a sstable

## Usage

``` r
ss_header(sstable, rows)
```

## Arguments

- sstable:

  a data frame following sstable's grammar

- rows:

  a numeric vector

## Value

a matrix of class ss_tbl

## Examples

``` r
m <- rbind(c("", "Arm A", "Arm B"), c("Age", "50", "48"), c("Sex", "", ""),
           c("- Female", "5 (50%)", "6 (50%)"))
m <- ss_header(m, 1)
m <- ss_body(m, c(2, 4))
m <- ss_section(m, 3)
rownames(m)
#> [1] "header.1"  "body.1"    "section.1" "body.2"   
ss_flextable(ss_format(m, .guess = FALSE))
```
