# Flextable theming for sstable

Theming flextable for sstable

## Usage

``` r
ft_sstheme(ft, bg = "#F2EFEE")
```

## Arguments

- ft:

  flextable

- bg:

  a character string, the background colour of odd body rows.

## Value

the themed flextable.
